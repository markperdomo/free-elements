Free Elements tools

Select text boxes or AutoShapes on one slide, then open Home → Free Elements in PowerPoint. Choose the reference shape in the Ref list. Hover for tool names, or enable Labels at the bottom. Extra numeric controls expand under Shape values and Text values.

Position and size

Equal gaps keeps the outer shapes fixed. Fixed spacing keeps the leftmost or topmost shape fixed. Match size preserves centers or top-left corners. Grid orders shapes from top to bottom, then left to right. Swap works on exactly two shapes.

Shape

Choose the actual shape kind: chevrons, right arrows, or rounded rectangles. All selected shapes must be the same kind and unrotated. These tools change the existing shapes and retain their text, fill, and outline.

  • Angles: match the reference’s point angle while retaining each shape’s dimensions.
  • Chain: align right-facing chevrons, matching the reference’s dimensions and handles. The reference stays fixed; Gap controls horizontal space between corresponding angled edges.
  • Handles: copy the reference’s proportional handle settings to matching shapes.
  • Arrow: set a constant arrowhead depth in points and shaft thickness as a percentage of height.
  • Radius: give rounded rectangles the same physical corner radius in points, even when their sizes differ.

Use Shape values for radius, head depth, and shaft percentage. The shape kind is an explicit choice; the tool checks handle counts but cannot identify every AutoShape type automatically.

Text

Margins opens four independent text margins in points. Set margins applies those values; −1 and +1 change every existing margin by one point. Paragraph alignment is below the margin controls.

Fit box allows the shape to resize to its text. Fit text shrinks overflowing text inside the shape. No fit turns automatic resizing off. Wrap toggles wrapping for all selected shapes; a mixed selection turns wrapping on.

Bullets, numbering, plain paragraphs, and indent/outdent operate on the paragraphs of the selected shapes. Existing words and font runs are preserved.

Split and merge create copies. Split one box into a box per paragraph. Merge two or more boxes in top-to-bottom, then left-to-right order. Originals remain intact. New boxes use the font, size, text color, and bold values in Format, and appear offset slightly from the originals. Copies contain plain text; they do not carry over hyperlinks, mixed font runs, or original bullet definitions. Move the selected copies where you want them.

Formatting and saved formats

Use the Format checkboxes to choose which properties to apply. Applying font settings makes those properties uniform across the selected shapes. Capture supports opaque solid fills, simple solid outlines, and uniform fonts. Saved formats stay in this browser or task pane.

Undo and compatibility

Click the slide and press ⌘Z for PowerPoint Undo, or use PowerPoint’s Undo button. Playground Undo applies only to the browser example. Choose a playground example to try chevrons, arrows, rounded rectangles, or multiline text.

Groups, pictures, tables, charts, and rotated shape geometry are not supported by these tools. Advanced Shape and paragraph controls are disabled on older PowerPoint versions. The browser approximates text metrics; PowerPoint uses its native text layout. Cursor-based splitting and language shortcuts are not implemented.

Keep the local HTTPS server running while using this development build.
